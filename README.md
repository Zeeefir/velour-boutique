# VELOUR

Демонстрационный бутик шуб: 12 моделей, поиск, фильтры, сортировка, сравнение, избранное, гид по размерам, корзина, промокод WELCOME10 и подарочная упаковка.

## Запуск

Требуется Node.js. Зависимостей нет.

- `npm run dev` — сайт на http://127.0.0.1:4173
- `npm test` — проверка корзины, скидок и файлов сайта

## Публикация

Vercel: импортировать репозиторий, Framework Preset — Other. `vercel.json` указывает каталог `dist`; сборка не требуется.

## Ограничения

Оплата демонстрационная: банковские данные не запрашиваются, деньги не списываются. Каталог, корзина, избранное и настройки сохраняются только в браузере. Кабинет управления не имеет защищённой авторизации и изменяет каталог только на этом устройстве. Запись на примерку не отправляется в магазин. Для реальной торговли нужны сервер, авторизация владельца и платёжный провайдер.

Иллюстрации созданы с помощью Imagegen; модели, цены и привилегии демонстрационные.
